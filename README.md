# dnmusic — escritorio

Acá solo cuelgan los instaladores de **dnmusic** para Windows y Linux. No hay
código: este repo existe para que la app pueda buscar sus actualizaciones sin
necesitar credenciales de nadie.

## Bajarla

En [Releases](../../releases), la última:

- **Windows** — `dnmusic-x.y.z-instalador.exe`
- **Linux** — `dnmusic-x.y.z-x86_64.AppImage` (dale permiso de ejecución y va)

## Se actualiza sola

Cuando hay una versión nueva la baja en segundo plano —nunca mientras estés
escuchando algo— y la aplica al cerrar la app, que vuelve a abrirse ya
actualizada. No hay que bajar nada a mano dos veces.
